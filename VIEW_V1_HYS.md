
## Contexto de producto — PILOTO REAL
H&S Gestión se está preparando para un piloto con usuarios reales.

El objetivo de este rediseño NO es alcanzar todavía una interfaz final de producción, sino una versión:
- profesional,
- coherente,
- intuitiva,
- estable,
- suficientemente pulida para validar el uso real.

Priorizar:
1. claridad de tareas,
2. navegación intuitiva,
3. diferenciación correcta por perfil,
4. reducción de redundancias,
5. comprensión rápida del estado de la obra,
6. preservación de los flujos funcionales ya validados.

No invertir tiempo en esta fase en:
- animaciones,
- microinteracciones complejas,
- buscador global,
- centro avanzado de notificaciones,
- personalización de dashboards,
- dark mode,
- métricas sofisticadas,
- funcionalidades decorativas o no esenciales para validar el piloto.

Una mejora visual sólo debe incorporarse si ayuda a entender, ejecutar o validar mejor el producto durante el piloto.
